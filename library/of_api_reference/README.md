# OnlyFans API Reference

Per-endpoint reference for the OnlyFans `api2/v2` surface, derived from
live browser-session recordings (the now-retired `plan_allAPIs` capture run).
Each file documents one endpoint: category, hit counts by account context,
Chatterly callsites that use it, observed UI surfaces/pages, sample
request/response sizes, and the response-body shape.

Static-asset and media (`/static`, `/files`, `/public/files`) captures were
dropped — they carry no API shape. Only the 72 real `api2/v2` endpoints are kept.
